  FRAMELINK  ─────────────────────────────────────────────────────────────────────────────────────────

  →  <a href="https://www.framelink.quest/">www.framelink.quest</a>

  Wireless PC-VR to a Quest 3. A cross-platform data plane, native capture, encode and
  decode at each end, and a Bun control surface holding the session together — built to see
  how far a self-made streamer gets against Air Link and Virtual Desktop.

   packages/protocol                Zig — the shared wire contract and its C ABI
   pc-streamer                      Zig — frame sharding, pacing, transport metrics
   sim-receiver                     Zig — reassembly and presentation on the headset
   apps/ui                          Bun control daemon and dashboard API
   apps/consumer-ui                 Svelte operator control and session view
   broker · auth                    The TypeScript services behind the control plane
   quest-link-bridge                Meta Quest Link (XRSP) protocol RE, bridged to SteamVR
   beamng-mcp                       Bundled: drive and sense BeamNG.drive from an MCP client
